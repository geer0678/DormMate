# DormMate 宿舍环境智能监测系统

## 1. 项目简介

DormMate 是面向宿舍环境记录与观察的课程项目。用户在网页中输入温度和湿度，系统通过固定阈值判断环境状态、生成对应建议，并保存每次分析记录。历史数据可导出为 CSV，由 Python 批量统计并生成报告和图表，帮助使用者查看温湿度变化及需要关注的记录。

项目还提供摄像头预览、单次拍照、中文语音识别、固定语音指令和语音播报，形成“网页交互—历史记录—数据导出—离线分析—报告展示”的操作流程。当前温湿度来源为手动输入，环境判断采用规则映射。

## 2. 项目功能

| 功能 | 当前实现 |
| --- | --- |
| Web 端温湿度环境检测 | 输入温度、湿度并点击分析；拦截空值、非数字和超范围数值 |
| 九种环境状态判断 | 组合温度的冷、适宜、热与湿度的干、适宜、湿，得到九种状态 |
| 环境建议生成 | 为九种组合提供对应文字建议，显示在结果区并保存到记录中 |
| 历史记录保存 | 使用浏览器 `localStorage` 保存时间、温度、湿度、状态和建议；刷新后读取历史 |
| CSV 数据导出 | 下载包含全部当前历史记录的 `dormmate.csv`，采用带 BOM 的 UTF-8 编码 |
| Python 数据分析 | 读取 CSV，对全量记录重新判断九状态并计算统计结果 |
| TXT / HTML 分析报告 | 自动生成统计摘要、九状态数量及重点关注记录 |
| 温湿度趋势图 | 使用 Matplotlib 绘制两条折线，保存为 `analysis/trend.png` |
| 环境状态统计图 | 绘制九种状态的记录数量柱状图，保存为 `analysis/status_chart.png` |
| 摄像头功能 | 用户主动打开、预览和关闭摄像头；关闭时停止视频轨道 |
| 单次拍照功能 | 点击“拍照”截取当前画面并显示到 Canvas，每次拍照更新该画布 |
| 语音识别 | 使用浏览器语音识别接口进行单次中文识别，显示识别文字与状态 |
| 语音指令控制 | 将固定语句映射到分析、历史查看、导出、摄像头和播报操作 |
| TTS 语音播报 | 朗读文本框内容、播放最近一次分析建议及停止播放；分析成功后约 300 ms 调用建议播报 |

## 3. 系统架构

系统由原生前端、Python 数据分析模块和浏览器语音交互模块组成。HTML 定义页面，CSS 提供布局与样式，JavaScript 负责交互和规则判断；Python 通过文件读取数据，生成可由浏览器打开的分析结果。摄像头和语音模块调用浏览器接口，无需项目自建应用服务器。

```text
用户输入温湿度 / 点击按钮 / 语音指令
                    ↓
          JavaScript 输入校验与环境分析
                    ↓
       状态与建议显示、TTS 建议播报
                    ↓
      历史数组与 localStorage 保存记录
                    ↓
             导出 dormmate.csv
                    ↓
       手动放入项目 data/dormmate.csv
                    ↓
       run.py 执行 Python 统计与绘图
                    ↓
     TXT / HTML 报告 + 两张 PNG 图表
                    ↓
     打开报告，或刷新首页查看静态图表
```

语音分析指令使用输入框中已有的温湿度，不会从自然语言中自动提取温湿度。摄像头预览与拍照是独立的页面操作，不参与温湿度计算。

首页统计卡片读取浏览器历史，首页两张图读取 Python 生成的 PNG。只有在使用同一批历史导出 CSV 并重新运行 Python 后，两类展示的数据来源才对应。

## 6. 环境状态判断规则

网页允许的输入范围为温度 **0～50℃**、湿度 **0～100%**，上下限均包含。空值、非数字或范围外数值会显示错误提示，不进入状态判断，也不追加历史。

有效输入按两个维度独立分类：

- 温度：低于 18℃ 为偏冷；18℃ 至小于 30℃ 为适宜；达到 30℃ 为偏热。
- 湿度：低于 40% 为偏干；40% 至小于 75% 为适宜；达到 75% 为偏湿。

| 温度分组 \ 湿度分组 | 偏干：低于 40% | 适宜：40% 至小于 75% | 偏湿：达到 75% |
| --- | --- | --- | --- |
| 偏冷：低于 18℃ | 偏冷偏干 | 偏冷 | 偏冷偏湿 |
| 适宜：18℃ 至小于 30℃ | 偏干 | 正常 | 偏湿 |
| 偏热：达到 30℃ | 偏热偏干 | 偏热 | 偏热偏湿 |

前端为每个组合保存对应建议，例如偏冷偏干时提示保暖和适当增加湿度，偏热偏湿时提示通风、降温和降低湿度。Python 报告及状态图使用相同分类阈值重新计算状态，报告中的建议文字取自 CSV 的 `advice` 字段。

## 7. 语音指令说明

先点击“开始语音识别”，再说出固定指令。当前识别配置为中文 `zh-CN`、单次识别；语音分析前应先填入有效的温湿度。

| 指令 | 实际执行的操作 |
| --- | --- |
| 分析环境 | 调用 `analyzeButton.click()`，分析当前输入 |
| 检测环境 | 调用同一分析按钮 |
| 查看历史记录 | 平滑滚动到历史表格，并播报“已为你打开历史记录。” |
| 导出数据 | 调用 `exportButton.click()`，下载当前历史 CSV |

| 关闭摄像头 | 调用 `stopCamera()` 停止视频流并关闭预览 |

当前代码还保留“查看环境”作为分析指令的别名。指令采用完整匹配，匹配前去除首尾空白及代码支持的句末标点；仅包含“环境”等词语不会触发分析。非指令识别结果仍显示在页面并填入 TTS 文本框。

上述八条指令及别名已通过对当前脚本的内存模拟分发检查，其中历史查看的滚动与播报调用也已核对。这类测试验证代码调用关系；真实语音识别、声音输出和视频预览仍需在演示设备上授权并现场验证。

## 8. 数据分析模块说明

### 8.1 CSV 输入

前端导出格式如下：

```csv
time,temperature,humidity,status,advice
```

每条新记录包含本地日期时间 `YYYY-MM-DD HH:mm:ss`、温度、湿度、九状态结果和建议。三个 Python 脚本均以 `utf-8-sig` 读取 `data/dormmate.csv`，使用浮点数解析温湿度，支持小数。报告脚本会清理表头的 BOM 和首尾空白；缺少建议列时使用“暂无建议”。

### 8.2 统计与关注记录

`analysis/analysis.py` 计算记录总数、温湿度平均值、最大值、最小值、九状态数量、异常次数及异常比例，并列出全部非“正常”记录的时间、数值、重算状态和原始建议。

```text
平均温度 = 温度之和 / 记录数
平均湿度 = 湿度之和 / 记录数
异常次数 = 记录数 - 正常记录数
异常比例 = 异常次数 / 记录数 × 100%
```

Python 不直接采用 CSV 中已有的 `status` 作为统计结论，而是重新按温湿度判定。

### 8.3 图表与报告

| 输出 | 内容 |
| --- | --- |
| `analysis/report.txt` | 温湿度统计、九状态数量、异常比例和重点关注记录 |
| `analysis/report.html` | 摘要卡片、统计表、重点关注表及两张图表引用 |
| `analysis/trend.png` | 按 CSV 行顺序展示温度与湿度变化，使用原始时间字符串作为横轴标签 |
| `analysis/status_chart.png` | 九种状态的数量柱状图，标注各状态记录数 |

`run.py` 依次执行 `analysis.py`、`chart.py`、`status_chart.py`，子进程使用启动它的同一 Python 解释器；任一子进程返回非零状态时流程停止。图表保存为 PNG 后关闭绘图对象。

当前仓库附带的 9 条数据及已有报告摘要如下，后续替换 CSV 并重跑后结果会随数据改变：

| 项目 | 已有报告结果 |
| --- | --- |
| 记录数 | 9 |
| 平均温度 / 最低 / 最高 | 25.67℃ / 16℃ / 35℃ |
| 平均湿度 / 最低 / 最高 | 56.11% / 30% / 85% |
| 正常 / 异常记录数 | 2 / 7 |
| 异常比例 | 77.78% |

当前 CSV 保留了部分早期四状态标签，例如 `16℃、35%` 仍记录为“偏冷”，已有报告则重算为“偏冷偏干”。这是输入文件的历史内容，重跑分析不会改写该 CSV；浏览器中旧记录的标签也不会自动迁移。

## 9. 运行方法

以下命令在项目根目录的 Windows PowerShell 中执行。

### 9.1 准备 Python 环境

当前开发机已有 `.venv`，可直接检查解释器：

```powershell
.\.venv\Scripts\python.exe --version
```

在新机器或不存在可用虚拟环境时，先准备带 `venv` 和 pip 的 Python；当前已使用过的版本为 3.13.13。确认 `python` 指向准备使用的解释器，再创建环境：

```powershell
python --version
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

这些命令直接使用虚拟环境解释器，不需要先执行激活脚本。不要直接复制其他机器的 `.venv`；当前环境依赖本机的 `.python` 路径。绘图代码使用 `Microsoft YaHei`，状态图还配置了 `SimHei` 备选字体；运行机器缺少对应字体时，中文图表文字可能无法正确显示。

### 9.2 启动网页

```powershell
.\.venv\Scripts\python.exe -m http.server 8000
```

保持终端运行，在浏览器打开 [DormMate 本地页面](http://localhost:8000/)。使用同一地址访问以继续读取同一浏览器来源下的历史。关闭服务器时在终端按 `Ctrl+C`。

基础页面也可直接打开 `index.html`；摄像头和语音功能请在支持相关接口的浏览器中通过本地 HTTP 页面演示，并允许相应设备权限。语音识别是否成功还取决于浏览器实现及识别服务的可用性。

### 9.3 生成分析结果

1. 在网页中输入有效温湿度，完成多次分析并形成历史记录。
2. 点击“导出 CSV”或使用“导出数据”语音指令。
3. 将下载的文件放入项目 `data/`，文件名保持为 `dormmate.csv`；需要更新数据源时替换原文件。
4. 在项目根目录的另一个终端运行：

```powershell
.\.venv\Scripts\python.exe run.py
```

5. 检查 `analysis/` 中四个输出文件，打开 [HTML 分析报告](http://localhost:8000/analysis/report.html)，或直接在浏览器打开 `analysis/report.html`。
6. 刷新首页查看更新后的图表；浏览器仍显示旧图时可强制刷新。分享 HTML 报告时，应同时保留同目录下的两张 PNG。

脚本使用相对路径，必须从项目根目录运行。网页只负责下载 CSV，不会自动替换项目数据源，也不会自动执行 Python。

### 10.5 当前使用限制

- 温湿度由用户输入；摄像头画面不用于温湿度测量。
- 历史记录保存在当前浏览器来源的本地存储中，不提供账号同步；清除站点数据会移除这些记录。
- CSV 与分析结果需要手动交接、重跑和刷新。旧记录状态不会因前端升级自动重写。
- 拍照结果保留在页面 Canvas 中，刷新后不保留；当前没有照片下载或连续录像功能。
- ASR、TTS 和摄像头操作依赖浏览器支持、设备及权限；普通识别文字不会被解析为温湿度输入。
- Python 按既定 CSV 列结构读取；缺列或无效数值可能中断分析，应使用页面导出的有效记录。

## 11. 项目亮点

1. **组合式环境判断**：温度和湿度独立分类，再组合为九状态，建议可以反映低温高湿、高温干燥等同时出现的情况。
2. **记录到报告的数据衔接**：通过包含日期时间、状态和建议的 CSV，把网页交互结果交给 Python 批量分析。
3. **统计可追溯**：报告同时提供总体指标与逐条关注记录，便于从异常比例追溯到具体输入。
4. **语音复用现有操作**：固定语音指令调用已有按钮和功能函数，实现分析、导出、历史查看与设备控制。
5. **建议与播报联动**：分析结果可以自动播报，语音“播放建议”可读取最近一次记录中的建议，历史查看也有声音反馈。
6. **便于本地演示**：原生网页配合 Python 标准库静态服务器即可展示，数据分析只需安装 Matplotlib，无需前端构建工具。
