# DormMate 微信小程序

项目目录：D:\我的小程序。用微信开发者工具导入该目录，然后点击“编译”。无需 npm 构建即可运行。保留现有 AppID；没有发布或上传版本。

## 迁移内容

| 网页功能 | 微信小程序对应实现 |
| --- | --- |
| 温湿度输入、九状态和建议 | 环境页；规则位于 utils/dormmate.js，阈值和建议与网页一致 |
| localStorage 历史 | wx 本机缓存；自动迁移该小程序原来的 history / dormmate_history_v2 |
| 网页既有历史 | 记录页提供14条网页 CSV 数据的导入快照；最新网页历史可用 CSV / JSON 导入 |
| CSV 导出 | 生成 UTF-8 BOM 的 dormmate.csv，点击“分享文件”后由用户选择保存或发送目标 |
| 平均值、极值、异常比例 | 分析页基于当前全部历史即时计算 |
| 温湿度趋势图 | 小程序 Canvas 2D；显示最近30条，按时间顺序，温度和湿度各自独立刻度 |
| 九状态数量图 | 原生水平柱状图，统计全部历史 |
| Python TXT 分析结果 | 小程序直接生成包含全部关注记录的 TXT；也可把 CSV 交给原有 Python 流程继续生成 HTML / PNG |
| 摄像头、拍照 | 原生 camera，支持前后摄像头、预览、保存到相册、权限失败处理 |
| 分析后自动播报、播放建议 | 九种建议的本地中文 WAV，无需在线插件 |
| 任意文字语音合成 | 已接入 WechatSI textToSpeech，需要后台开通后启用 |
| 语音识别和8条指令 | 已接入 WechatSI，结果执行与网页相同的操作；需要后台开通后启用 |
| 停止播报、离开页面清理 | 停止音频并取消迟到的语音合成；隐藏页面时停止录音和摄像头 |

四个分区：**环境、记录、分析、交互**。默认打开环境页。第一次打开不自动生成记录，现场分析后才保存。

## 当前在线语音状态：等待微信后台开通

后台开通属于微信账号操作，不能只靠修改代码完成。目前默认关闭在线插件声明，保证未开通的账号能正常编译环境、历史、图表、摄像头与离线播报。

1. 使用当前小程序的管理员账号登录微信公众平台。
2. 在“设置 → 第三方设置（或第三方服务）→ 插件管理”搜索“微信同声传译”。
3. 核对提供方 AppID：wx069ba97219f66d99。按后台实际提示申请或添加。能否添加以账号后台为准。
4. 记录后台显示的可用版本号。在项目目录运行：

   node scripts/configure-voice.js 后台显示的版本号

   例如后台确实提供 0.3.5 时才运行：node scripts/configure-voice.js 0.3.5

5. 脚本会同时更新 app.json 的插件声明和 config/speech.js；在开发者工具重新编译。
6. 根据微信后台要求完成隐私保护指引中的麦克风、摄像头、相册相关声明。然后用手机微信预览，授权麦克风，检查识别与自定义文字播报。

如果后台无法添加插件，保持关闭状态；须另接有资质、可用的语音服务才能完成在线语音实测。不要把密钥写进小程序。关闭插件命令：

## 历史数据如何迁入

网页与小程序的本地存储不互通，不能自动读取浏览器里的最新历史。

- 本项目附带当前网页 data/dormmate.csv 的14条快照。在“记录”页点击“导入网页已有14条记录”，检查后确认导入。
- 网页最新历史：在网页导出 CSV，通过微信文件传输助手把文件提供给手机，再用小程序“选择文件导入”选择。
- 也可粘贴 CSV，或粘贴 JSON 数组 / 含 history 数组的 JSON 对象。
- 输入须为 UTF-8，CSV 至少包含 time、temperature、humidity。时间格式为 YYYY-MM-DD HH:mm 或 YYYY-MM-DD HH:mm:ss。
- 导入前校验所有记录；任何错误都会阻止整批导入。按照时间、温度、湿度去重，同一秒相同读数合并为一条。
- 旧状态和旧建议按网页现行九状态重算。最多5000条；达到上限会提示先导出清理，不会静默丢弃旧记录。
- 清空当前历史只在用户确认后进行；旧版本缓存作为迁移备份保留，但不会在下次启动重新导入。

## CSV 和报告

CSV 字段保持 time,temperature,humidity,status,advice；从早到晚排列，支持小数、引号、逗号，兼容原网页 Python 分析脚本。点击“导出 CSV”只生成本机文件，再由用户点击“分享文件”选择目标。生成报告也在记录页提供相同的分享入口。环境不支持文件分享时可以使用“复制 CSV”。

主图最多显示最近30条，统计和报告使用全部记录。这是为手机可读性作出的范围限制，不是丢弃历史。

## 语音指令

分析环境 / 检测环境 / 查看环境、查看历史记录、导出数据、打开摄像头、关闭摄像头、播放建议、停止播放。

匹配前仅清理首尾空白和句末标点，采用完整匹配。普通话语只填入播报框，不当作操作指令。文字指令输入框可用于检查操作分发，但它不是语音识别。录音最长30秒，超过45秒仍没有返回会报超时。录音、拍照、插件识别需要手机授权及平台支持。

## 验证

    npm test

测试覆盖九状态与边界、无效输入、CSV 往返和坏格式、旧缓存迁移、统计、重开恢复、存储失败不产生假成功、指令解析、语音异步取消，以及界面事件绑定。

现场验收：
1. 关闭后重新打开项目；首次打开没有虚构记录，有已有历史时恢复。
2. 输入31℃/78% → 偏热偏湿；25℃/55% → 正常；16℃/35% → 偏冷偏干。
3. 输入空值、51℃或101%：显示错误，历史不增加。
4. 导入网页快照，重复导入不增加条数。检查分析页两张图和统计；导出CSV后再导入，记录不重复。
5. 导出TXT，核对平均值、极值、状态数量和关注记录。
6. 真机开启相机、等待就绪、拍照、预览、保存、关闭；拒绝权限后有明确提示。
7. 听取离线建议、关闭自动播报、停止播报。
8. 后台开通插件后，真机识别上述8类语音指令，播报自定义文字；检查拒绝麦克风和断网提示。

自动化实际界面检查需要微信开发者工具“设置 → 安全设置 → 服务端口”开启。单元测试和原生编译不等同于真机摄像头、声音及插件服务验收。

## 文件与范围

- utils/：统一业务、CSV、缓存、统计、语音和指令逻辑。
- components/trend-chart/：原生 Canvas 2D 趋势图。
- assets/audio/：本机 Windows 中文声音合成的10段 WAV，约0.94MB。
- data/web-history.js：网页导出的历史快照。
- scripts/configure-voice.js：后台开通后的插件配置工具。
- tests/：可复现回归检查。
- .migration-backup/：此次修改前的源码备份；不提交，不打进小程序包。
- artifacts/：本地编译与验证输出；不打进小程序包。

本轮范围是已有网页 M1–M3 功能迁移到 M4 原生小程序。M5 的本机 MQTT Dashboard、M6 的 Three.js 3D 实时场景属于后续任务，未包含在本次迁移验收中。
